# The ordinary closure

Two files, one `require_relative`, one cross-file call. It is the positive
side of the input-ledger controls: the twelve refusals beside it would also be
satisfied by an audit that refuses every ledger, so one closure has to be
accepted and audited to the end.

It is also the input the ledger and wire mangles are applied to. `main.rb` is
the entry, so `dep.rb` is a record the mangles can rewrite without removing
the entry the ledger must name.
