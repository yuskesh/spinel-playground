# The snapshot-escape probe

`main.rb` is generated by `audit.sh`, not stored, because the path it must
name is the absolute path of `dep.rb` on the machine running the test. The
shape is macOS's: `require_relative` climbs `../` far enough to reach the
filesystem root and then names `dep.rb` by its absolute path minus the leading
slash. It normalises back to this directory, the pinned reader accepts it, and
a snapshot taken of the two files still leaves the snapshot's own `main.rb`
reading THIS `dep.rb` rather than the copy.

Counting files does not see it: two frozen against two opened. The audit
compares the set by name and requires every path to be inside the snapshot.
